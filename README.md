# TradPlus MyTarget Adapter Swift Package

Swift Package Manager support for the TradPlus MyTarget adapter (15.13.0).

## Installation

```text
https://github.com/tradplus/TradPlusAdSDK-SPM-MyTarget.git
```

```swift
.package(url: "https://github.com/tradplus/TradPlusAdSDK-SPM-MyTarget.git", exact: "15.13.0")
```

Third-party dependency: MyTarget SDK `5.45.0`. Minimum iOS 14.

## Notes

- This package automatically resolves `TradPlusAdSDK` 15.13.0.
- Add `-ObjC` to the app target's `Other Linker Flags` if required.
